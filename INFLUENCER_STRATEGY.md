# 🎬 Nordic Automated Aura — Influencer-strategi for MajereAi

## Mål
Automatisert AI-influencer-kanal som genererer inntekt via affiliate marketing, sponsede samarbeid og digitale produkter — **uten manuell innsats**.

## Plattformer
- **TikTok** (primær — høyest viralt potensial)
- **YouTube Shorts**
- **Instagram Reels**
- Norsk + Engelsk innhold for dobbel målgruppe

## Tech Stack
| Komponent | Verktøy | Formål |
|-----------|---------|--------|
| Digital Twin | **HeyGen** | AI-avatar som snakker scripts |
| Scripting | **AI API** | Generer video-manus |
| Automasjon | **Make.com** | Limet: script → video → publisering |
| Affiliate | **Youfiliate** | Smarte linker (Amazon.no/.com) |
| Landing | **Cloudflare** | E-post capture + "Top Picks" |

## Pipeline (Zero-Touch)
1. **Trigger:** Make.com scheduler (daglig 08:00)
2. **Generer:** AI API lager script basert på trend
3. **Video:** HeyGen API lager video med digital twin
4. **Distribuer:** Auto-publiser til TikTok/Shorts/Reels
5. **Monetiser:** Youfiliate-sporede linker i bio

## Estimerte kostnader
- HeyGen: ~$100-300/mnd
- Make.com: ~$30-100/mnd
- AI API: ~$20-50/mnd
- **Totalt: ~$200-500/mnd**

## Tidslinje
- **Uke 1-2:** Sett opp HeyGen twin + sosiale kontoer
- **Uke 3-4:** Bygg Make.com workflow
- **Måned 2:** Daglig auto-posting
- **Måned 3-4:** Optimaliser basert på analytics
- **Måned 4-6:** Første inntekt
